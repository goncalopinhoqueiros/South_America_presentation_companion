SOUTH AMERICA PRESENTATION COMPANION — INTERACTIVE VERSION

Upload the contents of this folder to the root of your GitHub repository:
- index.html
- presentation.pdf
- assets/ (folder containing slide-01.jpg through slide-13.jpg)

On GitHub:
1. Open your repository.
2. Add file > Upload files.
3. Upload index.html, presentation.pdf and the entire assets folder.
4. Commit changes.
5. Settings > Pages > Deploy from a branch > main > /(root) > Save.

The page is mobile-friendly and includes a horizontally scrollable thumbnail strip,
a large selected slide, and a description card underneath. It also includes
previous/next controls, keyboard arrows, and swipe navigation.

The noindex directive discourages search-engine indexing but does not restrict access.
