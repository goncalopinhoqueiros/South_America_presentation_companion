ATUALIZAÇÃO DO WEBSITE — RESULTADOS SUPLEMENTARES

Conteúdo:
- index.html: versão atualizada do website, mantendo o visualizador dos 13 diapositivos e acrescentando uma secção de Resultados suplementares.
- supplementary/: sete figuras suplementares, com transparências achatadas sobre fundo branco para evitar barras/áreas pretas em composições.

Como atualizar o GitHub:
1. Descompacte este ZIP.
2. No repositório GitHub, substitua o index.html pelo novo index.html.
3. Carregue a pasta supplementary inteira para a raiz do repositório (ao lado de assets/ e presentation.pdf).
4. Faça Commit changes diretamente na branch main.
5. Aguarde a publicação e atualize o website com Ctrl+F5.

Não apague as pastas assets/ nem o ficheiro presentation.pdf: continuam a ser usados pelo visualizador da apresentação.
